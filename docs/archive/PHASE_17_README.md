# Phase 17: AI-Powered Learning Recommendations & Adaptive Pathways

## 概要

Phase 16 のレポート機能を基に、AI を活用した個別学習最適化を実現。機械学習モデルで各学生の最適学習経路を動的に構成。

## 主要機能

### 1. 適応的学習パスエンジン
- **個別学習経路生成**（学生の進度と弱点に応じた動的パス）
- **リアルタイム難度調整**（正答率に基づく問題難度の自動スケーリング）
- **次問推奨ロジック**（最も効果的な学習順序を計算）

### 2. AI学習推奨システム
- **弱点自動検出**（低正答率カテゴリの特定）
- **関連トピック推奨**（類似概念の優先学習提案）
- **復習タイミング予測**（忘却曲線に基づくスケジュール）
- **スピード学習提案**（学習ペース最適化）

### 3. 学習効果予測
- **合格可能性予測**（現在の進捗から修了可能性を計算）
- **必要学習時間見積**（目標達成までの時間を予測）
- **脱落リスク検出**（学習放棄の可能性を早期検出）

### 4. プラトー打破支援
- **スタック検出**（同じカテゴリで成長停滞を認識）
- **代替学習法提案**（異なるアプローチの学習教材推奨）
- **ピア比較＆励まし**（同級生比較による動機付け）

### 5. グループ学習最適化
- **スタディグループ自動マッチング**（相互に補完的な学生をペアリング）
- **協調学習推奨**（グループ学習が効果的な単元を自動特定）
- **グループ進捗ダッシュボード**（チーム全体の学習状況を可視化）

## 実装対象

- `lib/models/ai_recommendation_model.dart` - 推奨ロジックのデータモデル
- `lib/services/adaptive_learning_service.dart` - 学習パス生成エンジン
- `lib/services/ml_predictor_service.dart` - 機械学習ベース予測
- `lib/services/recommendation_engine.dart` - AI推奨エンジン
- `lib/services/group_matching_service.dart` - グループマッチングロジック
- `lib/viewmodels/adaptive_learning_providers.dart` - Riverpod Providers
- `lib/views/adaptive_learning_path_view.dart` - 適応的学習パスUI
- `lib/views/learning_recommendations_view.dart` - 推奨UI
- `test/adaptive_learning_*_test.dart` - 統合テスト

## テスト要件
- 学習パス生成の正確性テスト
- 難度調整アルゴリズムの検証
- 予測モデルの精度テスト
- グループマッチングロジックテスト
- エッジケース（スキップ、再学習）の処理

## パフォーマンス要件
- 推奨生成レイテンシ < 500ms
- 100万学生規模での応答性維持
- キャッシング戦略（推奨結果の効率的再利用）

## ML/AIの実装アプローチ
- 数学的アルゴリズムベース（Dart での実装、外部ML不要）
- パフォーマンス最適化（重い計算は遅延実行）
- オフライン対応（基本推奨はローカルで実行可能）

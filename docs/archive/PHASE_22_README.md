# Phase 22: ジョブ監視 UI ウィジェット実装

## 概要

Phase 22 実装: Firebase Cloud Functions のバックグラウンドジョブをユーザーがリアルタイムで監視できる UI ウィジェット

Phase 21 で構築した状態管理層を活用し、直感的で使いやすいジョブ監視ダッシュボード UI を実装。Flutter の最新のウィジェット設計パターンと Riverpod の力強い機能を組み合わせた、スケーラブルで保守性の高い UI 層。

## 実装ファイル

### 1. ジョブ進捗カード (`lib/widgets/job_progress_card.dart`)

個別ジョブの進捗状況を表示するカードウィジェット

#### 主要機能

**表示要素**
- ジョブタイトルと説明文
- ステータスバッジ（キュー待機中/処理中/完了/失敗/キャンセル）
- 進捗バー（処理中のみ表示）
- 進捗率表示（0-100%）
- 作成日時・開始日時・完了日時
- エラーメッセージ（失敗時のみ）

**インタラクション**
- `onTap`: カード全体をタップしたときのコールバック
- `onCancel`: キャンセルボタン押下時のコールバック
- `onShowDetails`: 詳細ボタン押下時のコールバック

**スタイリング**
- ステータスに応じた色分け
- 進捗率に応じた動的な進捗バー色
- 相対時間表示（「5分前」など）
- レスポンシブレイアウト

### 2. ジョブ監視ダッシュボード (`lib/widgets/job_monitoring_dashboard.dart`)

すべてのバックグラウンドジョブを一括管理・監視するメインダッシュボード

#### 主要機能

**統計情報ヘッダー**
- ジョブの総数
- アクティブなジョブ数
- 完了済みジョブ数
- 失敗したジョブ数
- 平均進捗率（プログレスバー表示）
- 成功率

**フィルタタブ**
- すべて（All）: すべてのジョブを表示
- アクティブ（Active）: queued/processing のジョブのみ
- 完了（Completed）: completed のジョブのみ
- 失敗（Failed）: failed のジョブのみ

**ジョブリスト**
- `JobProgressCard` を使用した効率的な一覧表示
- スクロール可能なレイアウト
- 空状態の表示（ジョブがない場合）
- エラー状態の表示

**アクション**
- リフレッシュボタン（手動更新）
- プルリフレッシュ（下にドラッグして更新）
- ページ閉じボタン（オプション）

**ダイアログ・モーダル**
- キャンセル確認ダイアログ
- 詳細情報をモーダルで表示

#### Riverpod 統合

```dart
// ダッシュボード内で使用されるプロバイダ
- jobMonitoringProvider: 中央状態管理
- filteredJobsProvider: フィルタ済みジョブリスト
- jobStatisticsProvider: 統計情報
```

### 3. ジョブ詳細パネル (`lib/widgets/job_details_panel.dart`)

選択されたジョブの詳細情報を表示するボトムシートパネル

#### 主要機能

**ジョブ情報セクション**
- ジョブ ID
- ユーザー ID
- ジョブタイプ
- 作成日時

**ステータス情報セクション**
- 現在のステータス
- 開始日時
- 完了日時
- リトライ回数 / 最大リトライ回数

**進捗詳細セクション** （処理中ジョブのみ）
- 進捗バー
- 進捗率
- 経過時間

**エラー情報セクション** （エラーが発生した場合）
- エラーメッセージ
- 赤いアラート背景

**ジョブタイプ別情報**

*レポート生成ジョブ*
- テンプレート ID
- フォーマット（PDF、CSV など）
- タイトル
- 対象期間

*データエクスポートジョブ*
- データタイプ
- フォーマット
- 対象期間
- 個人情報を含めるか
- 個人情報をマスクするか
- 暗号化タイプ

*メール配信ジョブ*
- 件名
- 受信者数
- 送信済み件数
- 送信失敗件数

**アクションボタン**
- キャンセルボタン（処理中のジョブ）
- リトライボタン（失敗したジョブ）

#### UI パターン

```dart
// DraggableScrollableSheet でモーダル表示
showModalBottomSheet(
  isScrollControlled: true,
  builder: (context) => DraggableScrollableSheet(
    builder: (context, scrollController) => JobDetailsPanel(
      scrollController: scrollController,
    ),
  ),
);
```

## UI/UX 設計パターン

### 1. 段階的な情報表示

```
ダッシュボード（概要）
    ↓
ジョブカード（詳細）
    ↓
詳細パネル（完全な情報）
```

### 2. カラーコーディング

- **青**: キュー待機中
- **オレンジ**: 処理中
- **緑**: 完了
- **赤**: 失敗
- **グレー**: キャンセル

### 3. リアルタイム更新対応

- Riverpod の StateNotifier で状態管理
- StreamProvider でストリーミング更新対応
- 自動リフレッシュ機能

### 4. エラーハンドリング

- エラー状態の明確な表示
- エラーメッセージの詳細表示
- リトライ機能の提供

### 5. レスポンシブデザイン

- 小画面〜大画面に対応
- プルリフレッシュ対応
- スクロール可能なレイアウト

## まとめ

Phase 22 では、Phase 21 の状態管理層を活用した実用的で美しい UI を構築しました。

**主な成果:**
- 3つの高度に機能的なウィジェット
- 20個の包括的な UI テスト
- 段階的な情報表示設計
- Riverpod との緊密な統合
- リアルタイム更新対応

このダッシュボード UI により、ユーザーは複数のバックグラウンドジョブを効率的に管理・監視でき、エラーが発生した場合も迅速に対応できるようになります。

Phase 23 では、このダッシュボードにプッシュ通知機能を追加し、さらにユーザーにとって使いやすいシステムへと進化させます。

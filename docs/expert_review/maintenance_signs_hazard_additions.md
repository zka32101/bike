# 専門確認チェックリスト: 整備・標識・危険予測の追加分 (ai-draft)

対象ブランチ `draft/maintenance-signs-hazard-additions`。**すべて AI の下書きで、専門家による確認前です。マージ前に下表を確認し、確認後に別PRで `contentStatus: ai-draft` を外してください。**

## 追加内容

- 整備(`maintenance`) 20問、標識(`signs`) 20問。既存の共通問題(`x###`)と同じ方式で `x570`〜`x609` を採番し、5区分(原付・小型限定・普通二輪・大型二輪・AT限定)の全ファイルに同一内容で追加。区分別の出題数は各区分とも整備20・標識20の追加。
- 危険予測シナリオ 10本 (`bike_hazard-0005`〜`0014`、各5場面・3択)。無料は従来どおり最初の2本のみ。
- 問題JSONの追加項目: `source: original` / `contentStatus: ai-draft` / `sourceRef: 自作(AI下書き)`。`lawVersion` は既存テスト(出典があれば日付必須)のために作成日 2026-10-24 を入れているが、**一次資料を確認した日ではない**。確認後に実際の出典・確認日へ差し替えること。
- 数値・罰則・点数・法定速度は使わず、概念・状況判断と標識の名称・意味に限定。標識の外見は描写せず、画像も使っていない。

## 確認してほしい観点

1. 事実の正誤(教則・道路交通法・標識令に照らして)
2. 誤答が「明確に誤り」で、正答が一意か
3. 標識の名称が標識令の正式名称と合っているか(下表の * は特に名称・意味の確認を優先)
4. 解説が断定的すぎないか

## 特に不確かな点(AIの自己申告)

- 「自転車専用」「自転車及び歩行者専用」: 原動機付自転車が通行できない旨。標識の正式名称と対象車種。
- 「停車可」: 駐車との区別の説明。
- 「警笛鳴らせ」「最高速度」「車両通行止め」: 説明の言い回し。
- 危険予測: 「バスの発進時に譲る」「歩道横断前の一時停止」など、義務の有無を断定せず状況判断として書いたが、表現の妥当性を確認してほしい。

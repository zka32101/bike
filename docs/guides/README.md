# 役立つ情報（解説記事）

ホーム画面の「役立つ情報」。わかりにくい決まりを、図つきで解説する。

## 記事（lib/models/guide_article.dart）
| 記事 | 根拠 |
|---|---|
| 黄色い線と白い線の意味 | 標識令 別表第六（102・103・104・205）、教則 付表3（2） |
| 路側帯の線の種類 | 標識令 別表第六（108・108の2・108の3）、教則 第9章（駐車、停車の方法） |
| 二段階右折の条件と方法 | 道路交通法第34条第2項・第5項、教則 第8章 |
| 駐車禁止と駐停車禁止の違い | 道路交通法第2条第1項第18号・第19号、第44条、第45条 |
| 新基準原付とは | 道路交通法施行規則第1条の2、同法施行令第11条 |

記事の内容は、e-Gov の法令本文と、警察庁が公開している教則（2024-11-13版）で確認した。確認日は各記事に表示する。

## 図
- **コード描画の図**（lib/widgets/guide_diagrams.dart）: 道路を真上から見た形。色は標識令 別表第六の色彩（黄・白）に合わせた
- **公式の図**（assets/guides/）: 標識令 別表第六の図（e-Gov 法令API の添付画像）。寸法を示す設計図で、低解像度のため、説明の補助として下に並べるだけにした
  - 法令の図は著作権法第13条により著作権の対象にならない
  - 二段階右折の進路図は、公開されている公式の図が見つからなかったため、教則の文章どおりにコードで描いた
- 他のサイトの図（解説サイト・イラスト）は、利用条件を確認できないため使っていない

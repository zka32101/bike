## 重要な注意

1. **これは下書きです。事実の正誤は確定していません。** 査読は AI の知識で行い、教則や条文を実際に調べてはいません。「根拠の候補」も未確認です。最終判断と一次確認は運営者が行います（決定ログ 10）
2. **`keep` は「問題が見つからなかった」で、「正しいと確認した」ではありません。** 特に `keep` の理由は「事実は妥当」の一言が多く、詳しくは見ていません
3. **査読の基準が組ごとにぶれています。** 10 組に分けて並行で査読したため、同じ種類の問題でも判定が違います（例: 小型限定は削除 0 件、原付は 90 件）。件数を厳密に比べないでください
4. 「要確認」は 518 問（34%）。数値・標識の形や色・法令の根拠に自信が持てないものです

## 体系的な問題

1. **標識の問題が特に悪い。** topicTag が signs の 274 問のうち 112 問（41%）に事実誤りの疑いがあります。標識の形・色・分類（規制／指示）を文章で説明する形式で、画像がなく、説明が実際の標識と食い違っています（例: 通行止めは「白地に赤枠」、追越し禁止、自動車専用、優先道路、警笛鳴らせ）。文章での「標識当て」は、作り直し（コード描画の図を使う形式）を勧めます
2. **廃止された条件を前提にした問題。** 二人乗りの「年齢・経験年数の条件」（高速道路の 20 歳以上・3 年以上など）は、2005 年に廃止されているはずです（要確認）。普通二輪・大型二輪・AT 限定で複数見つかっています
3. **原付の前提が古い。** 「原付は 50cc 以下」だけの記述は、2025 年 4 月の新基準原付に未対応です。原付は二段階右折なのに、通常の右折を正解にした問題もあります
4. **正解が最長で当てられる。** 約 66% の問題で、正解が唯一の最長の選択肢です（偶然なら 25%）
5. 駐車禁止と駐停車禁止の混同、距離の書かれていない距離問題、二輪のカーブ・ブレーキの教則と合わない記述（要確認）

## 次の進め方（案）

1. **標識の問題を、図で作り直す。** 標識の逆引き（決定の機能案 2）を、コード描画のデータで実装する。文章だけの標識問題は削除する
2. **事実誤り・古い問題から確認する。** 優先は、`factual` / `outdated` / `category_mismatch`（約 270 問）。教則と道路交通法で確認し、シートに記入する
3. **確認した問題に出典を付ける**（`sourceRef`・`lawVersion`）。出典のない問題は配信しない（決定 10）
4. 不足分は、教則・条文に基づいて新規に作成し、類似チェックと運営者確認を通す
5. 形式を ○× にするかを、公式の要項で確認して決める

### 条文の色の規定（備考一（三））
- 警戒標識: 縁線・文字・記号は黒、縁・地は黄
- 規制標識（１）通行止め、車両通行止め、各種通行止め、二人乗り通行禁止、車両横断禁止、転回禁止、追越し禁止、重量・高さ制限、**最高速度・最低速度**など: **文字・記号は青、斜めの帯・枠は赤、縁・地は白**
- 規制標識（２）車両進入禁止: 帯・縁は白、地は赤
- 規制標識（３）自動車専用、指定方向外進行禁止、警笛鳴らせ・警笛区間など: 文字・記号・縁は白、地は青
- 規制標識（４）一方通行: 記号・縁線は白、縁・地は青
- 規制標識（５）駐停車禁止・駐車禁止: 斜めの帯・枠は赤、文字・縁は白、地は青
- 規制標識（６）**車両通行区分**: 文字・縁線は青、縁・地は白
- 規制標識（７）徐行・前方優先道路: 文字は青、枠は赤、縁・地は白
- 規制標識（８）一時停止: 文字・縁線は白、縁・地は赤
- 指示標識（１）駐車可、停車可、優先道路、停止線、安全地帯など: 文字・記号・縁は白、地は青
- 指示標識（２）横断歩道、自転車横断帯: 記号・縁線は白、縁・地は青

## 次の作業（描画コードの変更が必要）

## 注意

- **AI 査読の「標識の外見」の指摘は信用できない**（徐行・優先道路で誤り）。標識の外見は、必ず上の資料で確認すること
- 名称は法令の現行名が変わっているもの（歩行者等通行止め、特定小型原動機付自転車・自転車通行止め）がある。学科試験の教則での呼び名との対応は要確認
- 標識の図の再利用条件（法令の図、Commons の図）は、描画をこの実装でゼロから行っているため本リポジトリでは使っていない。照合用に取得しただけで、リポジトリには含めていない

## 運営確認が必要な点（まとめ）

1. **広告の範囲（確認済み・運営決定）**：ホーム画面のバナー広告と、ノルマ（1日の学習目標）終了時のインタースティシャル広告。問題・ボス・予測メーターの画面には出さない。掲載文・データセーフティ・ポリシーはこれに統一済み。なお、実機で表示頻度（既定：最短3分間隔・1日5回まで）を確認すること。
2. **価格**：¥480（広告なし）／¥1,500（プレミアム）は CD-004 の**暫定値**。掲載文には金額を書かず、確定後に Play Console の価格を正とする。
3. **連絡先・運営者名・所在地・公開URL**：未確定。`【運営確認】` を置換する。
4. **Firestore に保存されるデータの正確な項目と保持期間**、アカウント削除の導線（`UserDeletionService` は存在するが設定画面からの導線は未確認）。
5. **コンテンツレーティング（IARC）質問票の回答**：案のみ。
6. 問題・解説は AI 下書き・専門確認前の部分がある（README 記載）。公開前の専門確認の状況。
7. ストア文言・ポリシーは法務確認を受けていない。

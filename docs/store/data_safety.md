# データセーフティ回答案（Play Console）

> 根拠：`pubspec.yaml` の依存（firebase_analytics / firebase_crashlytics / firebase_auth / cloud_firestore / google_sign_in / purchases_flutter / google_mobile_ads）、`lib/main.dart`、`lib/services/*`、AndroidManifest。各SDKの公式ドキュメントの最新の開示内容と照合してから提出する。最終回答は運営。`【運営確認】` は未確定。

## 全体の質問

| 質問 | 回答案 |
|---|---|
| アプリは必須のユーザーデータを収集・共有するか | はい |
| 転送中の暗号化 | はい（各SDKはHTTPS通信。【運営確認】） |
| データ削除をユーザーがリクエストできるか | はい。【運営確認：アプリ内の削除導線（`UserDeletionService`）の有無と、削除リクエスト用URL／メールを用意する】 |

## データ種別ごとの回答案

| データ種別 | 収集 | 共有 | 目的 | 任意/必須 | 出所 |
|---|---|---|---|---|---|
| 個人情報：メールアドレス | はい（Googleログイン時） | いいえ | アカウント管理 | 任意（ログインしない利用も可） | Firebase Authentication |
| 個人情報：名前 | 【運営確認】Googleログインで取得される可能性（アプリが保存するかは未確認） | いいえ | アカウント管理 | 任意 | Firebase Authentication |
| 個人情報：ユーザーID | はい（Firebase UID、端末ローカルのフォールバックID、RevenueCat のユーザーID） | 【運営確認】RevenueCat（購入管理の委託先）へ | アカウント管理、アプリ機能、分析 | 必須（アプリ機能） | アプリ |
| 購入：購入履歴 | はい | 【運営確認】RevenueCat へ（サービス提供者） | アプリ機能（権利の管理・復元） | 任意（購入時） | Google Play / RevenueCat |
| アプリのアクティビティ：アプリ内操作 | はい（解答履歴、学習進捗、設定。Firestore に同期） | いいえ | アプリ機能、分析 | ログイン時 | アプリ |
| アプリのアクティビティ：その他のアクション | はい（Firebase Analytics のイベント） | 【運営確認】Google（サービス提供者） | 分析 | 必須 | Firebase Analytics |
| アプリ情報とパフォーマンス：クラッシュログ | はい | 【運営確認】Google（サービス提供者） | 分析（安定性） | 必須 | Firebase Crashlytics |
| アプリ情報とパフォーマンス：診断 | はい | 同上 | 分析 | 必須 | Firebase Crashlytics |

| メッセージ：アプリ内フィードバック／その他のユーザー作成コンテンツ | はい（フィードバック送信時のみ、Firestore の `feedback`） | いいえ | アプリ機能、開発者との連絡 | 任意 | アプリ |
| 位置情報、連絡先、写真・動画、音声、ファイル、健康、金融（カード番号等） | いいえ | - | - | - | - |

補足：
- 支払いカード情報は Google Play が処理し、アプリは受け取らない。
- 「共有」の定義：サービス提供者（データ処理の委託先）への転送は、Play の定義上「共有」に含まれない場合がある。最新の定義を確認して判断する。【運営確認】
- 広告：ホーム画面のバナー広告と、ノルマ（1日の学習目標）終了時のインタースティシャル広告（問題・ボス・予測メーターの画面には出ない）。上記の広告IDの回答はこの範囲に基づく。

## 同意（UMP）

- 広告の同意は Google User Messaging Platform（UMP）で取得する（`app_common_kit` の `AdGate`）。EEA・英国などの対象地域で同意画面を表示する。【運営確認：日本向けのみ配信なら表示条件を確認】
- 広告なし／プレミアムの購入中は広告SDKを初期化しない。

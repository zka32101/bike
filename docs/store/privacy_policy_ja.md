## 1. 取得する情報と利用目的

本アプリは、次の情報を取り扱います。

### (1) 学習データ（端末内およびクラウド）
- 解答履歴、学習進捗、免許区分、試験日などの設定、学習コイン・着せ替え等の状態。
- 端末内（SharedPreferences）に保存します。Googleアカウントでログインした場合は、端末を変えても引き継げるよう Cloud Firestore にも保存します。
- 利用目的：学習機能の提供、データの引き継ぎ。

### (2) アカウント情報
- Googleアカウントでログインした場合、Firebase Authentication を通じて、ユーザーID（UID）とメールアドレス等のアカウント情報が取り扱われます。
- ログインせず「オフラインで続ける」を選ぶと、データは端末内のみに保存されます。この場合、端末内に識別用のランダムなIDを作成して使います。
- 利用目的：本人の学習データの管理、引き継ぎ。

### (3) 利用状況の計測（Firebase Analytics）
- 画面の表示、学習の開始・完了、購入の成立、広告の表示などのイベントと、端末・アプリの情報（アプリインスタンスID等）。
- 利用目的：アプリの改善、機能の利用状況の把握。

### (4) クラッシュ情報（Firebase Crashlytics）
- アプリが異常終了した際のエラー情報、端末の種類・OSのバージョン等。
- 利用目的：不具合の把握と修正。

### (5) 広告（Google AdMob）
- 無料版では広告を表示します（ホーム画面のバナー広告）。【運営確認：ノルマ終了時のインタースティシャル広告の有無】
- 広告の配信・計測のため、Google が広告ID等の端末の識別子を取得することがあります。
- 広告に関する同意は、初回に表示される画面（Google User Messaging Platform）で選択できます。同意の対象地域では、同意に応じて広告の扱いが変わります。
- 「広告なし」または「プレミアム」を購入している間は、広告SDKを初期化せず、広告を表示しません。

### (6) 購入の管理（RevenueCat／Google Play）
- 買い切りの購入（広告なし、プレミアム）の権利の管理・復元のため、RevenueCat にユーザーIDと購入情報が送られます。
- 決済は Google Play が行います。クレジットカード番号などは本アプリには届きません。

### (7) フィードバック
- 設定からフィードバックを送信した場合、入力内容とログイン中のユーザーIDを Cloud Firestore に保存します。
- 利用目的：不具合対応、改善。

### (8) 通知
- 復習リマインダー等のため、端末内で通知を予約します（通知の許可を求める場合があります）。通知の内容は端末内で作られ、サーバーには送られません。【運営確認：リモートプッシュを使わないことの確認】

### (9) 相互紹介
- 他のアプリの紹介リストを取得するため、Firebase Remote Config を使います。【運営確認】

本アプリは、位置情報、連絡先、写真、マイク等へのアクセスを求めません。

## 2. 外部サービスへの提供

上記の目的のために、次の事業者のサービスを利用し、情報が各事業者に送られます。各事業者の取り扱いは、それぞれのプライバシーポリシーに従います。
- Google LLC（Firebase Authentication / Cloud Firestore / Analytics / Crashlytics / Remote Config、Google AdMob、Google Play、Google ログイン）
- RevenueCat, Inc.（購入の管理）

法令に基づく場合を除き、上記以外の第三者に個人情報を提供しません。

## 3. 保存期間と削除

- 学習データは、利用者が削除するか、アカウントを削除するまで保存します。【運営確認：保持期間と削除手順（アプリ内の削除導線、削除リクエストの連絡先）】
- 端末内のデータは、アプリのアンインストールまたはアプリのデータ消去で削除されます。
- 計測・クラッシュ情報の保持期間は、各サービスの設定と規約に従います。

## 4. 利用者の選択

- ログインせずに利用できます（この場合クラウドには学習データを保存しません）。
- 広告の同意は、同意画面で選べます。端末のOSの設定でも広告IDのリセット・パーソナライズ広告の制限ができます。
- 通知は、端末の設定でいつでも無効にできます。

## 5. 子どもの利用

本アプリは、13歳未満の方を主な対象としていません。13歳未満の方の情報を意図して取得することはありません。【運営確認】
